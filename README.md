# 📓 JournalApp – Enterprise-grade Journal Management System

**JournalApp** is a production-ready backend system designed for secure, scalable journal management. Built using the Spring Boot ecosystem, it features robust authentication with JWT, MongoDB for persistence, Redis caching, secure mailing, and comprehensive API documentation via Swagger/OpenAPI.

---

## 🚀 Features

- ✅ **JWT Authentication** (Access + Refresh Tokens)
- 🔐 **Role-based Access Control** with Spring Security
- 📦 **MongoDB Integration** for scalable document storage
- ⚡ **Redis Caching** for performance optimization
- 📧 **Email Service Integration** via Spring Mail
- 🧪 Input validation and testing
- 📚 Interactive API Docs with Swagger UI (SpringDoc)
- 🐳 Docker support for containerization and portability
